# Evaluación Frontend

Proyecto en angular v18.0.0 con UI ngprime y aplicando buenas practicas de desarrollo como son principios solidos y clean arquitecture

## Instala dependencias

Ejecuta `nmp install` 

## Levantar server modo desarrollo

Ejecuta `ng serve` ng serve para iniciar un servidor de desarrollo. Navega a http://localhost:4200/. La aplicación se recargará automáticamente
